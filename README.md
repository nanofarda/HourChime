# HourChime

اپ اندرویدی ساده برای **زنگ‌دار کردن ساعت به صورت ۱۲ ساعته**. 

## نحوه عملکرد

این برنامه در زمان‌های زیر به‌صورت خودکار صدا پخش می‌کنه:

| زمان | تعداد پخش | نوع صدا |
|---|---|---|
| :00 | برابر شماره ساعت در قالب ۱۲ ساعته (۱ تا ۱۲) | دینگ |
| :15 | ۱ بار | بینگ |
| :30 | ۲ بار | بینگ |
| :45 | ۴ بار | بینگ |

**نکته:** بین هر پخش، **۱ ثانیه فاصله** وجود داره.

## ویژگی‌ها

- پشتیبانی از ساعت ۱۲ ساعته
- برنامه‌ریزی با AlarmManager و setExactAndAllowWhileIdle
- بازنشانی خودکار آلارم‌ها پس از هر اجرا
- پشتیبانی از بوت شدن گوشی (BOOT_COMPLETED)
- قابلیت درخواست دسترسی SCHEDULE_EXACT_ALARM در اندروید ۱۲+
- استفاده از SoundPool و در صورت نبودن فایل‌های صوتی از ToneGenerator

## نحوه استفاده

1. برنامه رو اجرا کن
2. روی دکمه **«فعال‌سازی زنگ ساعت»** بزن
3. در صورت نیاز، دسترسی **Alarms & reminders** رو فعال کن
4. برنامه از این به بعد به‌صورت خودکار عمل می‌کنه
